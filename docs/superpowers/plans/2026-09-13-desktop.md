# Mola masaüstü uygulaması

**Amaç:** Mevcut Mola sunucusuna bağlanan Linux, macOS ve Windows istemcisi.

**Mimari:** Ayrı `desktop/` npm paketi Electron ile sunucunun mevcut arayüzünü açar. API, WebSocket ve oturum çerezleri aynı origin üzerinde kalır. Express/SQLite istemciye paketlenmez. Yerel kurulum ve ekran seçici sayfaları ayrı, kısıtlı IPC kullanır; uzak sayfada preload veya Node erişimi bulunmaz.

**Kararlar:** Sunucu adresi ilk açılışta istenir ve yerelde kaydedilir. HTTPS gerekir; yalnızca loopback geliştirmede HTTP kabul edilir. Her origin ayrı kalıcı oturum kullanır. Mikrofon/kamera için kullanıcı izni, ekran paylaşımı için kaynak seçimi gerekir. Aynı sunucudaki ekler uygulama oturumuyla indirilir. Görüşme için boş açılır pencere desteklenir; diğer siteler sistem tarayıcısında açılır.

## Uygulama adımları

- [x] URL doğrulaması, gezinme ve ayar saklama davranışlarını testlerle oluştur.
- [x] Yerel sunucu bağlantısı ve hata ekranı, Electron pencere/menü yaşam döngüsü, izinler ve ekran seçiciyi ekle.
- [x] Bağımsız masaüstü bağımlılıkları ve Linux AppImage/DEB, macOS DMG/ZIP, Windows NSIS paketlerini yapılandır.
- [x] Her hedef işletim sisteminde artifact üreten GitHub Actions akışını ve Türkçe kullanım rehberini ekle.
- [x] Birim testleri, gerçek Electron bağlantı/oturum/izolasyon provası, mevcut web derlemesi ve Linux paketini doğrula.

## Doğrulama sonucu

Web derlemesi ve mevcut 248 birim/entegrasyon testi geçti. Masaüstünde 8 politika/ayar testi, 9 gerçek Electron testi ve gerçek Mola API/Socket.IO üzerinden mesaj gönderme/kalıcılık testi geçti. Electron 44'ün ekran yakalamayı boş `mediaTypes` ile bildirmesi ve bildirim işçisinin `webContents` olmadan izin kontrolü yapması testlerde yakalanıp düzeltildi. Linux AppImage/DEB üretildi; paket içinden kurulum ekranı sandbox açıkken başlatıldı. macOS/Windows native derlemeleri bu Linux oturumunda çalıştırılmadı; CI iş akışı depoya eklendi, uzak ortamda henüz başlatılmadı.

## Kapsam sınırları

Uygulama çevrimiçi Mola sunucusu gerektirir. Yerleşik güncelleme, işletim sistemi bağlantı kaydı ve uygulama kapalıyken yerel push bu sürümde yoktur. Sertifika olmadan paketler imzasızdır. macOS/Windows derlemeleri yerel Linux makinesinde çalıştırılmış sayılmaz; CI sonuçları ayrı doğrulanır. Fiziksel medya aygıtları ve işletim sistemi izinleri hedef cihazlarda ayrıca denenir.
